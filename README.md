# Integrating Non-EU Digital Credentials with EDCL

**Requirements, Architecture, and a Ukrainian Case Study**

Course paper, M.Sc. Human-Centered Computing, Reutlingen University (2026)

## Summary

The European Digital Credentials for Learning (EDCL) framework lets learners
share machine-verifiable credentials across EU member states. It was designed
for EU institutions, so there is no defined technical path for credentials
from third-country digital systems. This affects many people, for example
from EU candidate countries such as Ukraine, whose qualifications exist
digitally but cannot be verified seamlessly within the EU system.

This paper looks at that gap using a design science approach that combines
standards analysis with an embedded case study. The case study uses Ukraine's
Diia digital documents platform and the EDEBO educational database, which the
paper describes as the most EDCL-ready third-country implementation.

## Contributions

- Analysis of the technical requirements for integrating third-country
  credentials with EDCL
- Identification of the gaps that must be bridged
- A proposed workflow and a data-structure mapping showing how Diia and
  EDEBO could be bridged to produce EDCL-compliant output
